# Портфолио — Умид Шамсиддинов

Сайт-портфолио младшего архитектора-проектировщика (рабочие чертежи), Ташкент.

## Запуск

```bash
cd site
npm install
npm run dev      # http://localhost:3000
```

Нужен Node.js 20 или новее.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `site/` | Рабочий сайт: Next.js 16, App Router, TypeScript. Подробности — в [site/README.md](site/README.md) |
| `Портфолио.dc.html` | Исходный дизайн главной из Claude Design. Эталон внешнего вида, в разработке не используется |
| `support.js` | Рантайм Design Components для файла выше |
| `ds/`, `_ds/` | Дизайн-система Nocturne: токены, компоненты, гайд |
| `assets/` | Иконки проектов, шрифт GOST Type A, референс обложки |
| `uploads/` | Исходные материалы от заказчика |

## Страницы

- `/` — интро-обложка, резюме, три проекта, контакты
- `/projects/flat`, `/projects/school`, `/projects/tower` — обложка проекта, описание и комплект листов А3 с полноэкранным просмотром

## Статус

Чертежи пока представлены листами-заглушками: реальные комплекты от заказчика ещё не получены. Как их подставить — описано в [site/README.md](site/README.md). Админка для редактирования контента запланирована, но ещё не разрабатывается; контент вынесен в `site/content/` и читается через единственный модуль `site/lib/content.ts`, чтобы её подключение не затронуло страницы.
