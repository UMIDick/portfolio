## Приложение `site/`

- Запуск: `cd site && npm install && npm run dev`. Подробности и структура — в `site/README.md`.
- Node.js на этой машине установлен портативно в `%LOCALAPPDATA%\Programs\node` (добавлен в PATH пользователя; в Git Bash при необходимости `export PATH="/c/Users/cr7um_geelv3s/AppData/Local/Programs/node:$PATH"`).
- Контент (резюме, контакты, проекты, листы) — JSON в `site/content/`, читается только через `site/lib/content.ts`; типы в `site/lib/types.ts`. Это точка подключения будущей админки/БД — страницы менять не придётся.
- Страницы: `/` (интро, резюме, проекты, контакты), `/projects/{flat,school,tower}` (обложка, описание, сетка листов А3, полноэкранный просмотр с клавиатурой/свайпом и ссылкой `#sheet-N`), 404.
- Листы сейчас — SVG-заглушки из `npm run placeholders`; реальные чертежи класть в `site/public/projects/<slug>/sheets/` и описывать в `site/content/sheets/<slug>.json`.
- Стили: токены Nocturne и шрифт в `site/app/globals.css`, остальное — CSS Modules рядом с компонентами. Только `Intro` и `SheetGallery` — клиентские компоненты.
- Админку пока не делать (решение заказчика); архитектура под неё подготовлена (см. раздел «Контент и будущая админка» в `site/README.md`).

## Исходный дизайн (Claude Design)

- `Портфолио.dc.html` — главная страница (Design Component: шаблон `<x-dc>` + логика `class Component extends DCLogic` + tweak-пропсы в `data-props`). Открывается напрямую в браузере вместе с `support.js`.
- `support.js` — рантайм Design Components (шаблоны `{{ }}`, `<sc-for>`, `<sc-if>`, `style-hover`). Не редактировать.
- `ds/styles.css` — токены и классы дизайн-системы Nocturne (копия из `_ds/`).
- `_ds/nocturne-*/` — исходник дизайн-системы Nocturne (readme.md — гайд, styles.css, _ds_bundle.js).
- `assets/icons/*-dark.png`, `*-light.png` — иконки трёх проектов (flat, school, tower) в тёмной и светлой темах.
- `assets/icons/telegram-plane-tight.png` — маска логотипа Telegram (окрашивается через CSS mask в currentColor).
- `assets/fonts/GOST_A.ttf` — шрифт GOST Type A (только обычное начертание; жирного файла пока нет — браузер синтезирует).
- `assets/cover-ref.jpg` — референс обложки от архитектора; `assets/crops/` — увеличенные фрагменты для сверки глифов.
- `uploads/` — исходные файлы от заказчика (иконки, обложка, шрифт, скриншоты).

## Что сделано на главной

1. **Интро (полный экран)** — обложка перерисована в HTML: плитки-буквы PORTFOLIO (ряд 4), ARCHITECTURE (колонка 7), 2026 (колонка 1), UMID (ряд 9) на сетке 11×12 с шагом `--u * 1.1`. Каждая буква — сетка 6 строк × 4–5 колонок маленьких «u» (глифы в `GLYPHS`, сверены 1:1 с обложкой). PORTFOLIO/UMID — скруглённые плитки с полной обводкой; ARCHITECTURE/2026 — со срезанными углами (чередование по чётности строки), обводка сверху/справа/снизу. Плитки слетаются из хаоса (CSS transition, каскад по индексу).
2. **Резюме** — имя, специализация, образование, опыт, инструменты (теги), языки.
3. **Проекты** — три квадратные карточки-ссылки (`#project-1..3`), тёмная иконка, при наведении плавно показывается светлая + подъём с тенью. Подписей и кнопок нет — кликабельна вся карточка.
4. **Контакты** — две карточки в стилистике иконок проектов (Telegram @su_working, Email umidshamsiddinov1404@gmail.com): светлые по умолчанию, при наведении инвертируются в тёмные; подпись видна только при наведении; логотипы по центру.
5. **Анимации при прокрутке** — `animation-timeline: view()` + `@keyframes rise/draw`: блоки всплывают каскадом, разделители прочерчиваются. В Firefox играют один раз при загрузке.

Tweaks (панель): `introSpeed` (0.4–2.5), `replayIntro` (переключить — переиграть интро), `showScrollHint`.

## Правила дизайна (соблюдать при развитии)

- Дизайн-система **Nocturne**: тёмный фон `var(--color-bg)`, ramps `--color-neutral-*` / `--color-accent-*`, радиусы/тени из токенов. Заголовки не жирнее 500.
- Шрифт **везде GOST Type A** (`@font-face` в helmet). Когда заказчик пришлёт жирный файл — добавить второй `@font-face` с `font-weight:700`.
- Цвета обложки: белый `#e9e9ed`, лиловый `#c08aa5` / `#3f2d3b`, коричневый `#b39373` / `#3a2f2c`, синий `#7d95bf` / `#1e2a3e`. Контактные карточки используют синий и лиловый.
- Стили только inline (в `.dc.html`), в `<helmet><style>` — только `@font-face`, `@keyframes`, body-reset.
- Иконки — Phosphor; логотип почты — SVG в стиле присланного заказчиком.
- Заказчик даёт правки часто и точечно — менять только то, что просили.
